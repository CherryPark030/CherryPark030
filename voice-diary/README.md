# 🌙 말로 쓰는 일기 (Voice Diary)

침대에 누워서 핸드폰을 보지 않고, Claude와 **말로 수다 떨면** 그 대화가 일기로 정리돼요.

- 📱 화면 안 봐도 돼요. Claude 앱 **음성 모드**로 대화해요.
- 🙋 Claude가 오늘 하루에 대해 질문을 하나씩 던져요.
- 🧼 거칠게 말하거나 욕을 해도 괜찮아요. 감정은 살리고 표현은 순화해서 적어 줘요.
- 💸 **추가 비용 0원**이에요. Claude 구독만 있으면 되고, API 키도 서버도 필요 없어요.

## 처음 한 번만 설정 (5분)

1. Claude 앱 또는 claude.ai에서 **프로젝트(Projects) → 새 프로젝트**를 만들어요. 이름은 예를 들어 `🌙 일기`로 해요.
2. 프로젝트의 **지침(Instructions)** 칸에 [`project-instructions.md`](./project-instructions.md)에서 `---` 사이 내용을 복사해 붙여 넣어요.
3. 끝이에요.

## 매일 밤 쓰는 법

1. 폰에서 Claude 앱을 열고 `🌙 일기` 프로젝트에서 **새 채팅**을 시작해요.
2. **음성 모드(🎙️ 버튼)**를 켜고 폰을 내려놓아요.
3. "일기 쓰자"라고 말하면 Claude가 질문을 시작해요. 편하게 대답해요.
4. 다 이야기했으면 **"일기 써 줘"** 또는 **"잘게"**라고 말해요.
5. 정리된 일기는 그 채팅에 텍스트로 남아요. 다음 날 아침에 보면 돼요.

> 프로젝트 안의 채팅 목록이 곧 일기장이에요. 하루에 채팅 하나씩 쌓여요.

## 팁

- **알람처럼 습관 만들기:** 폰의 '취침 시간' 알림이나 단축어에 "Claude 열기"를 연결해 두면 잊지 않아요.
- **질문을 바꾸고 싶으면:** 지침의 질문 목록을 내 마음대로 고치면 돼요.
- **음성 모드가 프로젝트에서 안 켜지면:** 일반 채팅에서 음성 모드를 켜고, 첫마디로 지침 내용을 붙여 넣거나 "일기 친구 모드로 해 줘"라고 말한 뒤 시작해요. (지침을 Claude 설정의 개인 맞춤 지시에 넣어 둬도 돼요.)

## 나중에 더 해볼 수 있는 것

- 주간·월간 회고 ("이번 달 일기 요약해 줘"를 프로젝트에서 바로 물어봐도 돼요)
